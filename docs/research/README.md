# Research

Background material the information architecture and the design rules are derived from.

- `recruiter-perspective.md` — what recruiters (HR screening) and hiring managers (tech leads) need
  from a developer's personal site, what harms, German specifics (photo, language, Impressum, DSGVO,
  certificates), ATS-friendly PDF rules, GitHub expectations and how reviewers treat AI-assisted
  work in 2026. Compiled 2026-11-07 from Hacker News hiring threads, recruiter surveys (StepStone,
  Indeed, Gisma, Robert Half), German career portals and employer pages, with source links.
  Written in German because the maintainer's planning session was.

The architecture and convention analysis of the maintainer's other (private) projects and the
infrastructure facts that informed the hosting decision are not part of this public repository.
